Convert Support

Download, installation, everyday use and troubleshooting for Convert.

01

Download

Convert will be available from its MLDY Labs product page. Use the official download button there when the installer is published.

Convert Product Page →
02

Installation

  1. Download the Convert installer.
  2. Run the installer and complete setup.
  3. Launch Convert.
  4. Choose an output folder before your first batch if you want to change the default.
03

General Use

Drop files into the main window or choose them from your computer. Select one batch format for compatible files, or use the Individual Output control beside a file to override the batch setting. Review the output folder, then choose Convert Files.

04

Troubleshooting

  • Format is unavailable: that source file may not support the selected output format.
  • Conversion fails: verify the source file opens normally and is not damaged.
  • Cannot find converted files: check the Output Folder shown in Convert.
  • Large video/audio jobs: allow the conversion to finish before closing the app.
