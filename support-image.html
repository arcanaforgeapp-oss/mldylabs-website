02

Setup

  1. Download and run MLDY-Image-Setup-v1.1.1.exe.
  2. Complete the setup wizard.
  3. Launch Image from the Start menu.
  4. Select your output folder before processing your first batch.

No separate Python installation is needed.

03

Everyday Use

Add Files, Add Folder, or drag images into the window. Choose a preset or customize resize, quality, format, crop and metadata options. Check the images you want to process, review the output preview and destination, then choose Process Images. Existing output files are kept; duplicate names receive a number.

Supported inputs include JPG, JPEG, PNG, WebP, BMP and TIFF. Cancel stops the batch after the current image finishes.

04

Troubleshooting

  • App cannot start: reinstall using the complete official installer.
  • Processing fails: check that the source image opens normally and the output folder is writable.
  • Image stays small: check the Prevent enlargement setting.
  • Missing output: check Save to and use Open Output after processing.

This release is unsigned. As of October 2, 2026, VirusTotal reports detections from Microsoft, SecureAge and Skyhigh. Microsoft review of the bundled application EXE is pending. The installer is a separate file and has not yet been checked by VirusTotal. View the scan report. Do not disable antivirus protection to run it.

05

Removing the App

Close Image, then use Windows Settings → Apps → Installed apps → MLDY Image → Uninstall. Keep any processed images you want to retain. Preferences are stored separately under your Windows AppData folder in MLDY Labs/MLDY Image.
