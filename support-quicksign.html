QuickSign Support

Download, installation, everyday use and troubleshooting for QuickSign.

01

Download

QuickSign will be available from its MLDY Labs product page. Use the official download button there when the installer is published.

QuickSign Product Page →
02

Installation

  1. Download the QuickSign installer.
  2. Open the installer and follow the on-screen steps.
  3. Launch QuickSign from the Start menu or desktop shortcut.
  4. Open a PDF to begin editing.
03

General Use

Use the top toolbar to open/save documents and select editing tools. QuickSign supports text boxes, drawing, highlighting, signatures, checkboxes, form fields and redaction. The Pages panel lets you move through multi-page PDFs, while Tool Properties shows options for the active tool.

04

Troubleshooting

  • PDF will not open: confirm the file is a valid, readable PDF and try a local copy.
  • Form field is not detected: use a Text Box or Checkbox manually.
  • Signature does not appear: re-import the signature and place it again.
  • Changes missing: use Save or Save As before closing the document.
