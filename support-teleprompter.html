Teleprompter Support

Download, installation, everyday use and troubleshooting for Teleprompter.

01

Download

MLDY Labs Teleprompter will be available from its product page. Use the official download button there when the installer is published.

Teleprompter Product Page →
02

Installation

  1. Download the Teleprompter installer.
  2. Run the installer and finish setup.
  3. Launch MLDY Labs Teleprompter.
  4. Open an existing script or create a new one.
03

General Use

Add or open a script, then adjust scroll speed, text size and line spacing from the left controls. Choose text/background colors as needed. Use the playback controls or Spacebar to start and stop. Fullscreen mode is available for presentation, and the display can be used with mirrored teleprompter hardware.

04

Troubleshooting

  • Text moves too quickly: reduce Scroll Speed before restarting playback.
  • Text is difficult to read: increase Text Size or change foreground/background colors.
  • Script does not appear: confirm a script is selected and contains text.
  • Need to leave fullscreen: move the mouse to reveal the fullscreen exit control.
